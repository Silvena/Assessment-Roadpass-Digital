# Quarantine Directory

Tests placed here are known to be flaky and have been temporarily removed from the
PR gate. They still run nightly via the `quarantine-tests` CI job (informational only).

## Process

1. Copy the failing test here and add a comment with the tracking issue URL.
2. Remove the original from `trip-planner-happy-path.spec.js`.
3. Open a GitHub issue assigning ownership to the relevant team.
4. Fix and move back within the quarter, or delete if no longer valid.
